# Thomas Fischle

Software developer in Seattle, WA, working on embedded firmware, robotics, and GPU computing.

## Projects

- **[ObjectDetection](https://github.com/Thomas10111/ObjectDetection)**: robot object detection with YOLOv8 optimized with OpenVINO. Captures webcam frames, runs detection, and gives navigation hints from the object's position in the frame (Python).
- **[ObjectDetectionAndStateEstimation](https://github.com/Thomas10111/ObjectDetectionAndStateEstimation)**: a LEGO Technic car driven by an NVIDIA Jetson Orin. Small neural networks trained with PPO and imitation learning map the target's position from the camera (YOLOv8) to steering and speed; tested in Gazebo with the networks running on the Orin over ROS 2 and Zenoh (Python, ONNX Runtime).
- **[PyCuda_examples](https://github.com/Thomas10111/PyCuda_examples)**: examples of GPU kernels driven from Python with PyCUDA.
