# Thomas Fischle

Software developer in Seattle, WA, working on embedded firmware, robotics, and GPU computing.

## Projects

- **[ObjectDetection](https://github.com/Thomas10111/ObjectDetection)**: robot object detection with YOLOv8 optimized with OpenVINO. Captures webcam frames, runs detection, and gives navigation hints from the object's position in the frame (Python).
- **[LegoTechnicHub](https://github.com/Thomas10111/LegoTechnicHub)**: controls a LEGO Technic Hub over Bluetooth Low Energy from an NVIDIA Jetson using the LEGO Wireless Protocol (LWP3). All logic runs on the Jetson, next to the camera and neural network code (Python).
- **[ObjectDetectionAndStateEstimation](https://github.com/Thomas10111/ObjectDetectionAndStateEstimation)**: object detection and visual-inertial state estimation on a Jetson Orin; one camera stream shared by two networks, fused with an IMU.
- **[px4flow_OpticalFlowToPosition](https://github.com/Thomas10111/px4flow_OpticalFlowToPosition)**: converts optical flow from a PX4Flow sensor into an x, y, z position and publishes it; part of a quadcopter project at the University of Washington (2016).
- **[PyCuda_examples](https://github.com/Thomas10111/PyCuda_examples)**: examples of GPU kernels driven from Python with PyCUDA.
